# 04. 게임 로직 스펙

> 모든 수치는 제안값이며 `config` 형태로 분리 구현해 플레이테스트 후 조정 가능하게 할 것을 권장합니다.

## 1. 영역(그리드) 시스템

- 맵은 N×N 그리드 셀로 구성 (제안 시작값: 100×100, 셀 크기는 화면 해상도에 따라 스케일)
- 각 셀은 소유자 uid(또는 봇 ID)를 가짐, 미점유 시 null
- 플레이어가 자기 영역 밖으로 나가면 "궤적(trail)" 셀이 생성되고, 자기 영역으로 복귀하면 궤적으로 둘러싸인 영역이 폐곡선 채움(flood-fill) 알고리즘으로 점유 처리됨
- 이동 중 자신의 궤적 셀에 다른 플레이어가 닿으면 해당 플레이어 탈락(3장 참고)

## 2. 조작 모드 (2종, 선택 가능)

| 모드 | 방식 | 비고 |
|---|---|---|
| `classic` | 방향만 입력, 캐릭터 자동 전진 | 기본값, 배우기 쉬움 |
| `manual` | 이동 전체(정지 포함)를 직접 조작 | 레벨업/상점으로 해금, 스킬 표현 폭 넓음 — 밸런스상 랭크전 적용 여부는 미정 |

- 클라이언트 입력 처리: 마우스 좌표 또는 키보드(WASD/방향키) → 서버에 방향 벡터(및 manual 모드는 정지 여부) 전송
- 서버는 클라이언트 입력을 신뢰하지 않고, 이동 가능 여부(속도 상한, 그리드 경계)를 검증 후 상태 갱신 (치트 방지)

## 3. 탈락 및 부활 규칙

- 궤적이 노출된 상태(자기 영역 밖)에서 다른 플레이어/봇이 자신의 궤적을 가로지르면 탈락
- **부활 규칙 (제안, 확정 필요)**: 탈락 시 5초 리스폰 대기 + 기존 영토 50% 몰수 후 재투입 (완전 탈락 아님)
- 랭크전에서는 부활 없이 즉시 탈락 여부를 별도 결정 필요 (열린 질문)

## 4. 점수 및 가중치 존

- 기본 점수 = 최종 점령 면적(%) 
- **가중치 존(Value Zone)**: 배경이미지에 태깅된 좌표 기준, 해당 셀을 점령 시 배율 적용
  - `landmark` (고정 위치): x2~3
  - `gem`/`resource` (랜덤 스폰): 고정 보너스 점수 + 아이템 드랍
  - `event` (시간제 스폰, 예: 골드러시): x2~5, 한시적
- **랭크전**: `event` 존 비활성화, `landmark` 존만 유지 (공정성 확보, 예측 가능한 요소만 허용)

## 5. 이미지 공동 리빌 시스템

- 매치 시작 시 배경이미지는 전체적으로 가려진 상태(마스크)로 시작
- 어떤 플레이어든 특정 셀을 점령하면, 해당 셀에 대응하는 이미지 영역이 **전체 플레이어에게 공개**됨 (개인별 리빌 아님)
- 클라이언트 렌더링: Canvas에서 배경이미지를 텍스처로 깔고, 누적 점령 좌표를 알파 마스크로 적용 (`destination-in` 합성 또는 동등한 방식)
- 가중치 존과 연동: 이미지 내 태깅된 좌표가 리빌될 때 점수 보너스 지급 (4장 참고)

## 6. 봇 AI 스펙

| 티어 | 행동 |
|---|---|
| Lv.1 | 랜덤 이동, 자기 영역 내에서만 배회 |
| Lv.2 | 플레이어 영역 인식 → 궤적 노출 구간(약점) 추적 |
| Lv.3 | 2~3마리 협공 — 플레이어의 확장 경로를 예측해 차단 |

- 구현은 상태머신(순찰 → 추적 → 공격) 수준으로 충분, 초기 버전에 강화학습/딥러닝 불필요
- 봇은 실시간 서버 틱마다 상태 갱신 (docs/05-realtime-multiplayer.md 참고)

## 7. 파워업 (캐주얼 모드 한정)

| 아이템 | 효과 | 지속시간 |
|---|---|---|
| 스피드 부스트 | 이동속도 증가 | 3초 |
| 실드 | 궤적 피격 무효 | 5초 |
| 더블 영토 | 다음 1회 점령 면적 2배 인정 | 1회성 |
| 미니맵 레이더 | 주변 플레이어 위치 표시 | 3초 |

- 랭크전에서는 전체 비활성화

## 8. 스테이지(솔로 봇전) 클리어 조건

- `areaPercent`: 맵의 X% 이상 점령
- `surviveTime`: 제한시간 내 생존
- 클리어 시 별점(1~3★) 평가 — 점령률/생존시간/킬수 기준 (세부 배점 공식은 열린 질문)

## 9. 열린 질문

- 그리드 셀 크기 및 맵 해상도 최종값
- 서버 틱레이트(권장 20~30Hz) 확정
- 부활 규칙의 랭크전 적용 여부
- 별점 평가 세부 배점 공식
